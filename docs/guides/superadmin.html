SuperAdmin Guide

AI Client Portal — for SuperAdmins

Full, unscoped control of the organization — connecting AI providers, defining plans and budgets, routing and compliance rules, and everything every other role can do too.

Overview

As SuperAdmin, there is no boundary on what you can see or change — every department, every user, every setting. You're also the only role that can connect AI providers in the first place, which means nothing in the app runs at all until you've done that at least once.

What's exclusive to you (an Admin cannot do these, even for their own department): connecting/approving AI providers, Plan Management, Budget Automation, Smart Routing, Compliance Routing, Retention & Provider Approval, Data Handling, Capability Limits, Models (legacy), Departments, Feature Visibility, Branding, and Email Logs/SMTP settings. MFA is also always mandatory for you — it can never be turned off.

People & access

Unlike an Admin, you see and manage every department, and only you can create or remove departments themselves.

Users

Users

The master roster across the whole organization. Add accounts, edit role/department/team/email, reset passwords directly, suspend/reactivate, and change plans (single or bulk) for anyone, in any department.

Teams

Teams

Create or delete teams in any department.

SuperAdmin only → Departments

Departments

The org-chart itself. Create, rename, or delete departments, and set each one's monthly budget cap. From here you can also open a department's own system prompt (instructions baked into every AI reply for that department) and its shared prompt-template library.

Plans & money

Where subscription tiers, spending, and requests-for-more all live.

SuperAdmin only → Plan Management

Plan Management

Defines every subscription tier the organization offers — token/message/session/budget caps, which specific models the plan includes, which features it grants (file upload, export, priority routing, model selection, and more), demo/trial length, and which plan new signups land on by default.

SuperAdmin only → Capability Limits

Capability Limits

Numeric caps on specific actions rather than overall volume: maximum message length, maximum Compare-mode uses per day, and per-plan overrides for the Code Playground and Domain Generator daily-run limits.

Limits · Upgrade Requests

Limits & Upgrade Requests

Same tools an Admin has — per-user/department overrides on top of the Plan, and the queue of upgrade requests — but across every department, not just one.

SuperAdmin only → Budget Automation

Budget Automation

Once a user's month-to-date spend crosses a chosen percentage of their budget cap, new replies are automatically switched to a cheaper fallback model instead of being blocked outright — spend gets capped without anyone hitting a hard wall mid-conversation.

Automation & routing

How the app decides which model actually handles a message, before the user's own manual choice is even considered.

SuperAdmin only → Smart Routing

Smart Routing rules

"If the message looks like code / is a short casual question / has an image attached / has a long document attached, use model X" — a priority-ordered list of rules, checked before the app falls back to its own general complexity-based routing.

SuperAdmin only → Compliance Routing

Compliance Routing

A per-department hard ceiling on where requests are allowed to go at all — currently either "no restriction" or "EU-hosted models only." Sits on top of everything else and can only narrow access, never widen it.

Compliance & data

Controls for organizations with real data-handling obligations — none of this is on by default.

SuperAdmin only → Retention & Approval

Retention & Provider Approval

Two things live here: how long a department's conversations are kept before permanent deletion (30 days / 90 days / 7 years / forever), and the compliance sign-off every newly-connected AI provider must clear before any of its models can be enabled at all.

SuperAdmin only → Data Handling

Data Handling

Org-wide switches: restrict chat to zero-data-retention models only, turn PII scanning of outgoing messages on or off, mark which connected providers train on customer data, and configure what happens when the three built-in PII checks (national ID numbers, credit card numbers, phone numbers) catch something — block it, redact it, or just warn.

Models & providers

Connecting real AI providers and deciding exactly which of their models the organization actually uses — exclusively yours to do.

SuperAdmin only → Providers

Providers — the real workflow

This is the only place API keys are ever entered.

1. Connect — paste a provider's API key. It's tested live against the provider before anything is saved, so a bad key is never stored; a good one is encrypted, and only its last 4 characters are ever shown again.

2. Sync — pulls that provider's current model list. Run it again anytime ("Resync") to pick up new models or catch retired ones.

3. Approve — every newly-connected or freshly-synced provider sits in "Pending" on the Retention & Approval page until you sign off. Nothing from a pending provider can be turned on for chat.

4. Enable models — once approved, flip on the specific models that should actually be usable. A model can also be separately marked "manager-assignable," making it eligible for Managers to hand out individually via My Team.

5. Region — record where a provider actually hosts requests; this is what Compliance Routing's EU-only rule checks against.

Disconnecting a provider clears its key and force-disables every model that came from it.

SuperAdmin only → Models (legacy)

Models (legacy)

An older, simpler model registry kept for organizations that set models up before the Providers workflow existed. Enable/disable a model, edit its display name and per-1M-token pricing, delete one that's never been used, or open its per-user allow/deny list.

Monitoring & logs

Everything an Admin has, across every department, plus two screens exclusively yours.

Usage & Cost · Audit Logs · Feedback

Usage & Cost, Audit Logs, Feedback

The same tools an Admin has — spend dashboards, the admin action trail, and reply feedback — but org-wide. You also get a cross-department monthly summary export built for chargeback (Usage & Cost's export menu).

SuperAdmin only → Email Logs

Email Logs

Every email the app has actually sent — recipient, subject, whether it sent or failed, and whether it was opened — plus the SMTP connection settings that make outbound email work at all, and a "send test email" button to confirm they're actually correct before relying on them.

Branding & feature visibility

Shaping how the app looks and which capabilities each role sees — org-wide, exclusively yours.

SuperAdmin only → Branding

Branding

Replace the default name, tagline, logo, and favicon with the organization's own, everywhere at once — the sidebar, the browser tab, and the login page all update immediately. A logo replaces the text name entirely rather than sitting next to it. Reset to defaults at any time.

SuperAdmin only → Feature Visibility

Feature Visibility

Master on/off switches for whole app sections per role: which admin-nav sections an Admin sees at all (Teams, Upgrade Requests, Limits, Usage & Cost, Audit Logs, Feedback), and which chat/Settings capabilities User/Manager/Admin see (templates, quick-switcher, pin/search, dark mode, notifications, upgrade requests, onboarding tour, the two standalone tools). This is also where the org-wide "MFA required for Admins" switch lives.

Chat

You use the same chat screen as everyone else.

Model picker, Compare mode, attachments, export, templates, usage widget

Everything a User has — pick a model or let Smart Routing choose, Compare two models side by side, attach files, export conversations, use prompt templates, and track your own usage via the Usage pill.

Code Playground & Domain Generator

On by default for you. Reached by a direct link — not the main sidebar.

Code Playground & Domain Generator

Playground: pick a model, describe the code, run it in a simulated sandbox. Domain Generator: describe a business idea, get AI-suggested domain names checked for real availability. Both count against a daily quota you control in Capability Limits.

Security & login

MFA (email one-time code) — always mandatory for you

A 6-digit code emailed at login, valid for 10 minutes, with a resend option and a 5-attempt limit before login starts over. Unlike every other role, this can never be turned off for SuperAdmin.

Password reset & account lockout

Standard emailed reset-link flow. 5 wrong password attempts locks an account for 20 minutes; one successful login resets the counter.
