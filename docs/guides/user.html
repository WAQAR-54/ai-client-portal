AI Client Portal — for Users

Everything you can do with your account: chatting with AI models, comparing them, keeping track of your usage, and managing your own settings.

Overview

AI Client Portal is your organization's single place to chat with AI models — OpenAI, Anthropic, Grok, Gemini, DeepSeek — through one account, instead of signing up for each provider separately.

Your organization's admin has already connected the models, set your plan (which decides how much you can use and which models you can access), and can tighten or loosen your access at any time. If you ever need more than your plan allows, you can request an upgrade directly from the chat screen — no need to email anyone.

Not seeing a feature described here? Every feature below can be individually switched on or off by your admin, so your organization may not have all of them turned on.

Chat

The main screen — this is where you'll spend almost all your time in the app.

Starting and managing conversations

New conversation, pin, search, delete

The sidebar lists every past conversation, grouped by date, with the most recent at top. Pinned conversations get their own section above the rest so they never scroll out of reach.

How: click New conversation to start fresh. Hover any conversation for the pin and delete icons. The search box above the list filters by title as you type. Deleting removes it from your view (your admin can still see it for audit purposes).

Choosing a model

Model picker & Smart Routing

By default the app picks a model automatically for every message, based on rules your admin set up (for example: code-related questions go to a coding-strong model). You can override this and pick a specific model instead.

How: open the model dropdown at the top of the chat, or the quick-pick chips above the message box. A model your plan doesn't include shows a lock and which plan unlocks it — clicking it opens the upgrade-request flow instead of switching.

Compare mode (Arena)

Send one prompt to two different models at the same time and see both replies side by side — useful for genuinely comparing quality, tone, or speed before trusting one model with real work.

How: use the Chat/Compare switch above the message list, pick two models, and send. A "pick a winner" control lets you note which reply was better, purely for your own reference. Your plan may cap how many Compare exchanges you can run per day.

Working with content

File attachments

Attach a file to a message so the model can read it as context — PDFs, Word/Excel docs, plain text, CSV, Markdown, JSON, and images.

How: the paperclip icon in the composer. Your admin may limit file size or which file types you can attach.

Export a conversation

Take a full conversation out of the app as a file — for sharing, archiving, or pasting into another document.

How: the export menu on an open conversation offers PDF, Markdown, and plain text.

Prompt templates

Reusable starting points for the message box — save your own frequently-used prompts, and see any shared templates your admin has set up for your whole team or department.

How: type / as the first character in the message box, or open the Templates panel from the composer, to insert one. Save the current draft as a new personal template from the same panel.

Edit & regenerate

Editing an earlier message of yours re-sends it and regenerates everything that came after — for correcting a typo or steering the conversation differently without starting over. Regenerate replaces just one AI reply with a fresh attempt.

Feedback (thumbs up/down)

Rate any AI reply and optionally explain a thumbs-down. Your admin can see this feedback to understand how well the AI is actually working for your team.

Keeping track of usage

Usage widget & upgrade requests

A running total of how much of your plan's daily/monthly allowance you've used, plus your plan name and, on a trial, how many days are left.

How: the Usage pill at the top of chat opens this. If you need more, Request upgrade sends the request straight to your admin — no need to email anyone.

Making it your own

Light/dark theme, language, and shortcuts

A quick theme toggle sits in the chat header; a full Light / Dark / System picker and language choice (English, Urdu, Arabic) live in Settings. A quick-switcher (Ctrl/Cmd+K) jumps between conversations without touching the mouse.

Guided tour

A short first-login walkthrough points out New chat, the usage widget, and the model picker. It only shows once automatically, but you can replay it anytime from Settings.

Code Playground & Domain Generator

Two focused, single-purpose tools, separate from chat. Both are reached by a direct link (your admin will share it) — there is no link to them in the main sidebar — and both may or may not be turned on for you.

Code Playground

Pick a model (grouped by provider, each labeled Fast / Balanced / Powerful), describe what the code should do, and run it in a simulated sandbox. Each run counts against a daily quota (20 by default).

Domain Generator

Describe a business idea, optionally filter by TLD (.com / .co / .pk / .uk), and get 5 AI-suggested brandable domain names — each one checked for live availability. Same daily-quota pattern as the Playground.

Security & login

What keeps your account safe, and what happens if a login attempt goes wrong.

Password reset

Forgot your password? Request a reset from the login screen, and follow the emailed link to set a new one.

MFA (email one-time code) — optional for you

You can turn on an extra login step: a 6-digit code emailed to you every time you log in, valid for 10 minutes.

How: Settings → Security. It's entirely your choice — turn it on for extra safety, or leave it off. (Admins and SuperAdmins don't get this choice — it can be made mandatory for them.)

Account lockout

5 wrong password attempts locks your account for 20 minutes, with a dedicated "you're locked out" screen showing how long is left. One successful login resets this.
